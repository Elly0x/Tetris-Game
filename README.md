# Tetris em Python

Este é um jogo Tetris desenvolvido em Python utilizando a biblioteca Pygame. O projeto foi criado com o objetivo de praticar lógica de programação, manipulação de matrizes, e uso de bibliotecas gráficas.

## Funcionalidades

- Peças com formatos clássicos (I, T, O, S, Z, L, J)
- Cores aleatórias para cada peça
- Sistema de rotação
- Verificação de colisão e preenchimento de linhas
- Remoção de linhas completas com pontuação
- Tela de Game Over

## Requisitos

- Python 3.x
- Pygame (instale com o comando abaixo)

```bash
pip install pygame
Como jogar

Execute o arquivo tetris.py:

python tetris.py

Controles

Seta para esquerda: mover peça para a esquerda

Seta para direita: mover peça para a direita

Seta para baixo: acelerar a queda

Seta para cima: girar peça

Barra de espaço: queda instantânea

ESC: sair do jogo
